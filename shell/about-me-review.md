# About-me review

Your task in this session: propose changes to the notes in `_about_me/` from evidence in the vault.
Do not start other work. The path of the folder is at the end of this message.

## Rules

1. Read every note in `_about_me/` first.
2. Read the evidence: the lessons in `_lessons/`, and the "Important Decisions" and "Constraints / Blockers" lines of the 20 newest session logs. Use `ai-mem-search <term>` to find more evidence for a term.
3. Propose a candidate only when 2 or more different sources show the same pattern. A pattern from one source is not sufficient.
4. For each candidate, show: the proposed rule, the target note, and each source as a file path with the quoted line.
5. Call each candidate an inference. Do not state it as a fact about the user.
6. Show one candidate per message. Ask the user to accept, change, or reject it.
7. If a candidate conflicts with a current note, show the conflict and ask. Do not replace the current note.
8. Write only the candidates that the user accepts. Do not change other text in the notes.

## Format of the notes

- Keep the frontmatter of each note.
- Write each rule as one bullet: "* Do X. Why: Y." or "* Do not do X. Why: Y."
- Keep `non-negotiables.md` shorter than 1500 characters.
